# OPCUA EXAMPLE

This example uses the machine-data-model library to connect to an OPC UA server.

## Prerequisites

- Install the machine-data-model library
- Run the following OPC UA sample server using docker: https://github.com/Azure-Samples/iot-edge-opc-plc

## How to run the example

Launch the `connect.py` file using Python.

`connect.py` will use the `opcua.yml` data model file to connect to the OPC UA server.
